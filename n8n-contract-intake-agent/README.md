# ИИ-агент приёма заявок на согласование договоров (n8n)

Домашнее задание «Соберите свой первый воркфлоу». Quick Win — навык **A3 «Проверка комплектности пакета»**
(область SG1 графа навыков, этап 1 TO-BE «Инициация и автомаршрутизация»).

Telegram-бот на n8n: принимает заявку в свободной форме, ИИ извлекает поля карточки, код проверяет комплектность
(A3), подбирает маршрут согласования (A7), после подтверждения кнопкой регистрирует заявку (A8) в Data Table.
Есть цикл уточнений, память между сообщениями, RAG по регламенту и обработка ошибок.

## Быстрый старт

1. Создайте бота у @BotFather, в n8n добавьте Credential «Telegram API» (имя оставьте `Telegram account`).
2. Создайте Data Table `contract_requests` с колонками: `request_uid`, `chat_id`, `user_name`, `status`,
   `card_json`, `request_text`, `route`, `reg_number` (String) и `attempts` (Number).
3. Импортируйте `contract_intake_agent.n8n.json` (Import from file…), проверьте 4 узла OpenAI (№ 15, 16, 27, 30).
4. Publish и напишите боту `/start`. Сценарий проверки — раздел 8 руководства.

## Пересборка JSON из исходников

```bash
cd src
node build_workflow.js ..        # пишет ../workflow.json
node unit.js                     # проверки кода узлов
node strict_check.js             # JSON Schema соответствуют строгому режиму OpenAI
```
